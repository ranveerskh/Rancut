# RanCut 0.5.6 — UI polish update

This update keeps the tested editing, Creator Style, Auto Edit, transition, export and relink behavior from 0.5.5 and refines the creator workflow:

1. Compact top bar with clearer project, view, GPU and export actions.
2. Better viewer/timeline balance so the preview and edit surface remain usable together.
3. One-line, scroll-safe timeline toolbar with consistent button sizing.
4. Stronger keyboard-focus states and compact responsive controls.
5. Clear selected-clip checkmark and stronger selected/missing clip contrast.
6. More readable inspector tabs, grouped cards and sticky footer actions.
7. Cleaner Creator Style and Auto Edit cards without changing their behavior.
8. Framing previews and range controls use the same visual hierarchy.
9. Project Home cards now show Local/Pinned/recovery status badges.
10. Empty Project Home and viewer states provide direct next actions.
11. Trash/search empty states are clearer and batch-trash controls remain available.
12. Missing-media banner and media cards use one red warning language.
13. Status messages have neutral, warning and error presentation with live updates.
14. Scrollbars are thinner/subtle and work consistently in media, inspector and timeline areas.
15. RanCut purple/blue studio theme is preserved with small-screen responsive fallbacks.

The UI changes are presentation-only; the timeline model and renderer are unchanged in this release.
