# RanCut 0.5.9 Preview

## Included

- Help & About → Feedback submits Feature requests and Bug reports directly to
  RanCut Platform.
- No feedback draft file is generated or saved locally.
- Help Quick Start steps stay aligned and the dialog footer remains visible.
- Media, Styles, Transitions, Effects and Markers tabs wrap cleanly in narrow
  media panels.

## Required companion deployment

Before using Feedback in the desktop app, deploy the matching RanCut Platform
update. It creates `feedback_requests`, deploys the `license-api` function,
and publishes the updated private admin dashboard. See the included Platform
package's `FEEDBACK-SETUP.md`.
